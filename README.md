# Ashen Kingdom

🎮 Um RPG de texto sombrio onde suas escolhas importam.

## Sobre o jogo

Explore um mundo misterioso, enfrente criaturas,
faça escolhas e descubra os segredos de Ashen Kingdom.

## Classes

- ⚔️ Guerreiro
- 🧙 Mago
- 🏹 Arqueiro
- 🌑 Mago Renegado
